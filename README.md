# Killer Queen

A fan recreation of the gameplay of Killer Queen Arcade, built in Godot 4: local 5v5 for up to ten players, one joystick and one button each, with Bots filling every Seat nobody takes. A Match ends on the first Military, Economic or Snail Win.

**Status:** v1 is complete: the Day Map, 5v5 with Bot fill, and all three win conditions. Online play is the v2 goal, and the deterministic sim was built for it ([ADR-0002](docs/adr/0002-online-ready-determinism-from-v1.md)).

## Playing

Requires Godot 4.7.2. Open the project in Godot and press F5, or run the Godot binary with `--path .` from the repo root.

In the Lobby, press a device's button to join, move along the row of Seats with the stick, and press the button to lock in (or unlock). The ends of the row set each Team's Bot Difficulty. The Match starts once everyone is locked in.

| Device | Move | Down (Queen Dive) | Button |
| --- | --- | --- | --- |
| Gamepad | Left stick / D-pad | Down | Any face button |
| Keyboard 1 | A / D | S | Space |
| Keyboard 2 | Left / Right | Down | Enter |

Esc (or a pad's Start/Menu button) pauses: resume, rematch or quit to the Lobby.

## Development

Run the headless test suite (gdUnit4, vendored in `addons/gdUnit4/`):

```bash
bash scripts/test.sh
```

The script uses the winget install path for Godot; set `GODOT` to point it at another binary.

Dev builds have these keys:

| Key | Does |
| --- | --- |
| F1 | Debug overlay |
| F2 | Freeze / run |
| F3 | Step one tick while frozen |
| F4 | Slow motion |
| F5 | Live tuning editor (F6 saves to `data/tuning.cfg`) |
| F8 | Start a new live Match |
| F9 | Play back the last Match's Replay |

### Layout

- `sim/`: the Match simulation. Plain GDScript with integer maths, no nodes, physics, floats or clock, so a Match replays exactly from its inputs ([ADR-0001](docs/adr/0001-godot-4-with-headless-deterministic-sim.md)).
- `game/`: presentation. Runs the sim at 50 ticks/s, reads devices, draws and plays sound. No game rules.
- `data/`: tuning constants (`tuning.cfg`) and Map layouts (`maps/`).
- `test/`: gdUnit4 suites for the sim and for presentation logic.
- `CONTEXT.md`: the project's glossary. Code and docs use its terms.
- `docs/adr/`: architecture decisions. `docs/research/`: notes on the arcade game.
- `.scratch/`: the v1 spec and tickets.
